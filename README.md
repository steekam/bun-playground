# bun-playground

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

## Problems

Problem-set creation, updates, file contracts, and commands are documented in
[docs/problem-sets.md](docs/problem-sets.md).

Use [docs/cassidoo-core-10.md](docs/cassidoo-core-10.md) for the ten extracted
algorithm practice sets.

Use [docs/patterns/README.md](docs/patterns/README.md) to choose an algorithm
pattern, state its invariant, and connect it to local practice problems.

This project was created using `bun init` in bun v1.3.6. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
