# Longest Valid Parentheses

Return the length of the longest contiguous substring of `(` and `)` that is
balanced and properly nested.

Examples: `"(()" -> 2`, `")()())" -> 4`, `"" -> 0`.

Solve it in linear time. Compare a stack-boundary solution with a two-pass
counter or dynamic-programming formulation.
