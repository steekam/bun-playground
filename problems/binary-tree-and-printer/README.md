# Binary Tree and Printer

Given a binary tree in level-order array form, return its parenthesized
preorder representation: `value(left,right)`, omitting empty children. Return
`""` for an empty tree.

Source: Cassidoo #336 (https://cassidoo.co/newsletter/2024-01-21/). Fidelity: adapted. The issue prints an ASCII tree whose whitespace did not survive the newsletter, so this version returns a parenthesized preorder string.
