# Deck, Shuffle, and Draw

Using a deterministic seed, shuffle `cards` with Fisher–Yates and return the
first `draws` cards. The same seed must produce the same result.

Source: Cassidoo #434 (https://cassidoo.co/newsletter/2025-12-07/). Fidelity: adapted. Shuffling is seeded so the same seed gives the same draw order and the tests stay deterministic.
